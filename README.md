# 超级小爱 / 小爱同学 PC 版 —— 设备校验绕过

**中文** | [English](README.en.md)

让小米笔记本专属的「小爱同学 / 超级小爱」PC 客户端跑在**任意品牌**的电脑上。

仓库地址：https://github.com/zhonglike/xiaoai-agent-unlock

## 一、使用场景

**核心矛盾：你的账号和生态都是小米的，但电脑不是小米笔记本 —— 官方客户端直接拒绝安装。**

### 场景 1：小米手机 + 非小米笔记本，想用「小米互传 / 跨端协作」

手机是小米，笔记本却是联想、华硕、戴尔、惠普或 Mac。官方客户端装不上，
于是这些功能全部用不了：

- 手机与电脑互传文件、图片、剪贴板
- 通知接续、在电脑上接打电话
- 与 iPhone / 其他 Windows 设备之间的小米互传

绕过机型校验后就能正常登录使用，手机是小米就能一路打通。

### 场景 2：家里是小米生态，只有电脑是「外来的」

米家设备、小米耳机、小爱音箱一大堆，唯独电脑不是小米。
装上电脑端之后，语音助手、蓝牙耳机联动、跨设备控制都能归到同一个
小米账号下，不用再为了一台电脑去换整个生态。

### 场景 3：想用超级小爱的 AI 能力，但不想为它换电脑

新版超级小爱带的功能（官方介绍）：

- **工作助手**：搜索本机文件、控制应用程序
- **生活助手**：智能问答、查天气、陪伴闲聊
- **语音唤醒**：喊一声就能唤起
- 截图问答、屏幕理解等

这些本质上都是**软件能力**，跟你电脑什么牌子毫无关系，
只是被厂商的机型白名单锁住了。

### 场景 4：黑苹果 / 组装机 / 老笔记本

自装机、黑苹果、几年前的老本，主板型号五花八门，
官方白名单里永远不可能有它们。本工具是**通用**的：
读取你本机的真实机型，写进白名单，什么牌子都适用。

### 适用前提

- 需要一个小米账号（登录后才能使用）
- Windows 10 1803 以上，64 位系统
- C 盘留出 2–3GB 空间（否则会出现安装失败、MiService 装不上等问题，见第八节）

## 二、原理

小米的客户端在**两个环节**做机型校验，两者都在本地，**无服务端参与**：

**1. 安装程序**（`vJ_O_XiaoaiAgent_*.exe`）
校验写在 JSON 配置里（明文）：

```json
"support_tm_list": [ "TM2424", "TM2425", "TM2426", "TM2427", "TM2428" ]
```

**2. 已安装的程序**（`XiaoaiAgent.dll`）
启动时 `App.CheckSignatureAndPCType()` 同时校验文件数字签名和机型白名单，不通过就：

- `Application.Current.Shutdown()` 直接退出（日志：`exit on unsupport device.`）
- 回调 `InfoCheckerService.OnFail()` 把 `IsLegal` 置 false，隐藏主窗口

机型取值链路：`Win32_BaseBoard` 的 Product 值（如联想 `LNVNB161216`），
缓存到 `HKCU\Software\MI\XiaoaiAgent\Cache\PCModel`。

> 改注册表缓存**无效**：启动时会异步重查 WMI 并覆盖缓存值。

## 三、文件说明

|---|---|
| `install_any_pc.bat` | **任意品牌安装**：自动读取本机机型 → 写入安装包白名单 → 提权安装 |

| `patches/2.0.0.231/` | 2.0.0.231 的程序补丁 + 原版备份 |
| `patches/3.0.4.289/` | 3.0.4.289 的程序补丁 + 原版备份 |
| `tools/Patcher/` | 补丁生成工具（Mono.Cecil），程序更新后可重新生成 |
| `说明-详细分析.md` | 完整逆向分析过程 |
| `patches/` | 预编译补丁 DLL 及其原版备份（**来自小米的二进制**，见免责声明） |

程序补丁改的是 `XiaoaiAgent.dll` 里三个方法的 IL：

| 方法 | 修改 |
|---|---|
| `App::CheckSignatureAndPCType()` | 清空方法体，不再触发退出 |
| `InfoCheckerService::OnFail()` | 清空方法体，不再隐藏主窗口 |
| `LocalSettingsHelper::get_IsInSupportWhiteList()` | 直接返回 `true`，语音唤醒开关可见（仅 2.0.0.231 存在） |

## 四、操作步骤

### 步骤 1：下载官方安装包

到小米官网驱动页下载对应机型的最新安装包：

https://www.mi.com/service/notebook/drivers/TM2424

### 步骤 2：绕过机型校验安装

双击 **`install_any_pc.bat`**，把上面下载的安装包路径粘进去（或直接拖进去），回车。
脚本会自动读取你本机的机型并写入白名单，然后弹出 UAC —— 点「是」即可正常安装。

> 想装到非 C 盘（C 盘空间紧张时推荐）：
> `python patch_installer2.py "安装包.exe" "输出.exe" E 你的机型`
> 第三个参数是目标盘符。

### 步骤 3：给程序打补丁

安装完成后，双击 **`install.bat`**：

```
选择版本号  →  选 [1] 安装补丁
```

脚本自动定位安装目录（C/D/E/F/G 盘依次查找），备份原文件后替换。

### 步骤 4：启动

运行安装目录下的 `XiaoaiAgent.exe`，正常登录小米账号即可使用。

**还原官方原版**：运行 `install.bat` → 选版本 → 选 [2] 还原。

## 五、教学视频 / 字幕文案（可直接用于抖音）

**开场（0-3s）**
> 小米笔记本专属的「超级小爱」，其他品牌的电脑也能装了。

**痛点（3-8s）**
> 官方安装包有设备校验，非小米机型直接提示"暂不支持此设备"，装都不让装。

**第一步 · 绕过安装校验（8-20s）**
> 拿到官方安装包后，运行这个脚本，它自动读取你这台电脑的机型，写进安装包的机型白名单，再调用安装程序。任何品牌都能用，不用改代码。

**第二步 · 打程序补丁（20-32s）**
> 装完之后别急着开，程序本身还有一层校验，不通过会直接退出。运行补丁工具，选版本，一键替换，原文件会自动备份，想还原随时可以。

**收尾（32-40s）**
> 现在就能正常登录使用了。工具开源在 GitHub，搜索仓库 `xiaoai-agent-unlock`，地址在评论区。

**注意事项字幕（滚动）**
> 程序自动更新后补丁会失效，需要重新打一次补丁。

## 六、重要提醒

### GitHub 单文件 100MB 限制

官方 2.0 安装包 **361MB**，**无法直接 push 到 GitHub**（超过单文件 100MB 限制）。
两个可行方案：

1. **用 Releases 上传**（推荐）：GitHub Release 附件单文件上限 2GB，
   把安装包作为 Release 资源上传，README 里放下载链接。
2. **用 Git LFS**：`git lfs track "*.exe"` 后再 push（注意 LFS 免费额度 1GB）。

### 其他

- 程序自动更新后 `XiaoaiAgent.dll` 会被官方文件覆盖，补丁失效，重新执行步骤 3 即可；
  版本号变化时需用 `tools/Patcher` 对新版本重新生成补丁。
- 修改后的安装包数字签名失效，Windows 可能提示"未知发布者"，选"仍要运行"。
- 语音唤醒开关虽然会显示，但该功能依赖机型特定音频硬件，非小米机型上大概率不生效。
- 本工具绕过厂商机型限制，属非官方改动，可能违反软件许可协议。
  **仅供个人在本机研究与学习使用**，请勿用于商业用途，风险自负。

## 八、常见问题（实测踩坑，强烈建议先看）

### 1. 启动提示「MiService服务未启动，请修复后重试」

安装时如果 C 盘空间不足，`MiService2_Setup.exe` 这一步会**静默失败**，服务根本没注册。
检查（管理员 PowerShell）：

```powershell
Get-Service MiService*
```

**查不到 = 没装。** 解决办法：手动运行安装目录下的 `MiService2_Setup.exe`
（右键 → 以管理员身份运行），装完后应为 `Running` / 启动类型 `Automatic`。

### 2. 补丁打好后重启就失效 / 机型检测又出现

两个原因，都要排查：

**原因一：补丁没打到正式安装目录**（最常见）。
很多人只在复制出来的测试副本上打了补丁，重启后打开的是安装目录里的
官方原版，于是又被拦。核对安装目录里 `XiaoaiAgent.dll` 的 MD5
是否等于 `patches/<版本号>/XiaoaiAgent.dll`。

**原因二：程序自动更新覆盖了补丁。** 程序默认开着 WiFi 自动更新，
一旦更新就用官方文件覆盖。关掉它：

```powershell
Set-ItemProperty -Path 'HKCU:\Software\MI\XiaoaiAgent' -Name 'AutoUpdateAppWifiFlag' -Value 0 -Type DWord
```

> 副作用：程序不再自动升级。以后升级需手动装新包 + 重新打补丁。

### 3. 安装失败，退出码 -3

看日志 `C:\ProgramData\MI\XiaoaiAgent\Log\Installer.log.txt`，若出现：

```
ExtractArchive: [...\packages\*.7z] failed
Install failed: -3
```

**这是磁盘空间不足，跟机型校验无关**（校验这时已经通过了，属于误判）。
C 盘至少留 2–3GB。空间紧张时可用 `patch_installer2.py` 把安装目录改到别的盘：

```bash
python patch_installer2.py "官方安装包.exe" "输出.exe" E 你的机型
```

> 注意：即使把安装目录改到其他盘，解压过程仍需占用 C 盘临时空间约 500MB。

### 4. 打完补丁后程序仍然退出

检查是不是装完忘了补装 MiService（问题 1），新版客户端强依赖该服务。
